# Front-end delle conversazioni: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** una pagina web (HTML/CSS/JS senza build) servita da `python avvia.py --frontend` su `http://127.0.0.1:8002`, che inoltra `/api/...` al back-end dello step 7 e permette di elencare, creare, aprire ed eliminare conversazioni, inviare domande e comandi `/prompt`.

**Architecture:** nuovo pacchetto `src/frontend/` che non importa `assistente` né `backend`: `config` (variabili), `app` (Starlette: tre file statici fissi + proxy asincrono `httpx.AsyncClient` su `/api/{percorso:path}`), `__main__` (uvicorn), `statico/` (`index.html`, `app.js`, `stile.css`). Nei test il back-end è un `httpx.MockTransport`.

**Tech Stack:** Python 3.14, `starlette==1.10.0`, `uvicorn==0.54.0`, `httpx==0.28.1`, `python-dotenv` (tutte già presenti), pytest + plugin `anyio` (già installato con Starlette); JavaScript del browser senza librerie.

**Spec:** `docs/superpowers/specs/2026-11-13-frontend-design.md` (approvata il 2026-11-13; vincolante).

## Global Constraints
- Comandi dalla cartella `assistente-laboratorio/` con `.venv\Scripts\python` (da Bash: `.venv/Scripts/python.exe`).
- **Nessuna dipendenza nuova**, né Python né JavaScript; nessun CDN, nessun file esterno caricato dalla pagina.
- `src/frontend/` non importa `assistente`, `backend` né `archivio`. Unica modifica fuori dal pacchetto: `avvia.py` e il testo d'uso in `src/assistente/cli.py` e `src/backend/__main__.py`.
- Testi esatti (Python):
  - `back-end non disponibile: <causa>` (502, causa = `str(e)` o, se vuota, il nome della classe dell'eccezione)
  - `back-end non disponibile: tempo scaduto dopo <timeout:g> s` (502)
  - `Uso: python avvia.py [--http | --backend | --frontend]` (stderr, uscita 2, in tutti e tre i `main`)
  - `BACKEND_TIMEOUT deve essere un numero positivo di secondi, trovato '<grezzo>'.`
  - `FRONTEND_PORTA deve essere un intero fra 1 e 65535, trovato '<grezzo>'.`
  - log INFO `frontend in ascolto su http://%s:%d`
- Variabili: `BACKEND_URL` (`http://127.0.0.1:8001`, `/` finale tolto, vuoto → default), `BACKEND_TIMEOUT` (`960`, numero > 0 finito), `FRONTEND_HOST` (`127.0.0.1`, vuoto → default), `FRONTEND_PORTA` (`8002`, intero 1–65535), `LOG_LEVEL` (`INFO`). Nessuna obbligatoria. Precedenza: ambiente > `.env` del progetto.
- JSON degli errori del proxy: `Content-Type: application/json; charset=utf-8`, corpo `{"errore": "..."}`, `ensure_ascii=False` come nel back-end.
- Testi esatti (pagina) dalla spec, sezione «Comandi dei prompt» e «Invio e attesa»: `Errore: prompt sconosciuto '/<nome>'. Scrivere /prompt per l'elenco.`, `Errore: /<nome> non ha argomenti.`, `Errore: /<nome> richiede: <a1> <a2>.`, `Il messaggio non è stato salvato.`, `Il messaggio potrebbe non essere stato salvato: riapri la conversazione per controllare.`, `L'assistente sta rispondendo… (m:ss)`, `Comandi non disponibili: <errore>`, `Eliminare la conversazione «<titolo>»?`, titolo della scheda `Assistente del laboratorio`.
- **Un solo commit a fine step** (Task 5), dopo aver mostrato le prove all'utente; i task intermedi non fanno commit. Ogni task termina con `python -m pytest` verde. Staging selettivo: mai `lezione_3/`, `.env`, `dati/`, `.superpowers/`, file fuori da `assistente-laboratorio/`.
- Nei test, funzioni d'appoggio che cominciano con `test` vengono raccolte da pytest: usare altri nomi. Heredoc dal tool Bash alterano `\n`: per i sorgenti usare Write/Edit.

## Review Focus
1. **Risposta del back-end non JSON** (es. `500 Internal Server Error` in `text/plain` di uvicorn): il proxy la passa invariata; la pagina non deve rompersi su `response.json()` ma mostrare `errore <codice>` nell'avviso. → test del proxy in Task 2; ramo nella funzione JS `leggiErrore` in Task 4 e voce nella lista manuale.
2. **Testo con accenti, `€` ed emoji nel corpo** inoltrato byte per byte, in entrambi i sensi. → test in Task 2.
3. **Turno lungo che blocca il proxy:** mentre `POST .../messaggi` attende, `GET /api/conversazioni` deve rispondere. → test asincrono in Task 2.
4. **Percorsi fuori dai tre file** (`/config.py`, `/statico/index.html`, `/app.py`, `/..%2fconfig.py`) → 404, nessun file del pacchetto esposto. → test in Task 2.
5. **Doppio invio** (doppio clic su «Invia» o Invio ripetuto): un solo `POST`. La casella si disabilita **prima** della `fetch`. → Task 4 e voce nella lista manuale.
