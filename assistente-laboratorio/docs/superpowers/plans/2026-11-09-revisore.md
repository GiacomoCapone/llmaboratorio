# Revisore delle risposte: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un nodo revisore giudica la risposta finale dell'agente; se non è coerente la rimanda all'agente con il motivo, fino a `MAX_REVISIONI`; a fine turno bozze e indicazioni sono tolte dalla cronologia.

**Architecture:** nuovo modulo `revisore.py` (prompt, `Valutazione`, strumento obbligatorio, ripiego su «coerente»), iniettato come callable in `build_graph`; il nodo `revisore` decide l'esito (agente / fine) col limite, lo registra nello stato e nei log, aggiunge l'indicazione e rimuove i messaggi scartati con `RemoveMessage`.

**Tech Stack:** Python 3.14, LangGraph (`RemoveMessage`, `add_messages`), langchain-openai (`bind_tools`), Pydantic 2, pytest.

**Spec:** `docs/superpowers/specs/2026-11-09-revisore-design.md`

## Global Constraints
- Comandi dalla cartella `assistente-laboratorio/` con `.venv\Scripts\python`.
- Nessuna dipendenza nuova.
- Testi esatti: `INDICAZIONE_REVISORE = "Indicazione del revisore: la risposta precedente non è adeguata. Motivo: {motivo}. Rispondi di nuovo alla domanda dell'utente in modo completo."`.
- Log esatti (logger `assistente.grafo`): INFO `revisore coerente=%s motivo=%s → %s` con `sì`/`no` e destinazione `fine` o `agente (revisione %d/%d)`; WARNING `limite di revisioni raggiunto (%d): restituita l'ultima risposta`. Logger `assistente.revisore`, WARNING `revisore non disponibile: %s`.
- `MAX_TOKEN_REVISORE = 256`; `MAX_REVISIONI` predefinito 2, intero ≥ 1.
- Un solo commit a fine step (Task 6), nessun commit intermedio; ogni task termina con la suite verde.
- Staging selettivo: mai `lezione_3/`, file fuori da `assistente-laboratorio/`, `.env`.

## Review Focus
- Revisione dopo un passaggio con strumenti: la cronologia finale deve mantenere ogni tool call col suo `ToolMessage` (si tolgono solo bozza e indicazione) — Task 3, `test_revisione_dopo_strumenti_mantiene_le_coppie`.
- Risposta vuota dell'agente (testo vuoto, già gestito dal nodo `modello` con una ripetizione) che arriva comunque al revisore: il revisore non deve sollevare; l'esito arriva dal revisore simulato — Task 3, `test_risposta_vuota_passa_dal_revisore`.
- Turno successivo a una revisione: router e revisore del nuovo turno non vedono bozze né indicazioni (`scartati` riparte vuoto da `esegui_turno`) — Task 4, `test_turno_dopo_revisione_cronologia_pulita`.
- Motivo del revisore con parentesi graffe (`{`/`}`) nel testo: l'indicazione non deve rompere `str.format` — Task 3, `test_motivo_con_graffe`.
- `MAX_REVISIONI` con spazi (`" 3 "`) letto come 3 — Task 1, nel parametrizzato.
